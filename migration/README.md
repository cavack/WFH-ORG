# WFH-ORG Migration Workspace

This directory contains provenance and disposition metadata for the controlled migration from `cavack/wfh` and `cavack/wfh-dr` into the clean canonical `cavack/WFH-ORG` repository.

No runtime source file is admitted without a manifest record. The manifest is generated from frozen source revisions, reviewed to a final disposition, and verified for completeness before release certification.

Initial frozen inputs are established during Task 1 of the migration plan. Production remains unchanged until the final cutover task.
